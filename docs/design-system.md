# FocusFox Design System

## Design Goal

FocusFox should feel like a calm lofi desktop focus widget / focus player, not a
generic SaaS dashboard.

## Visual Keywords

- Frosted glass
- Translucent panels
- Soft white typography
- Subtle text shadow
- Lofi study atmosphere
- Quiet focus tool
- Minimal controls
- Soft mint / blue-gray / cream / gentle green
- Calm motion
- Player-like layout

## What to Avoid

- Generic SaaS dashboard look
- Heavy card grids
- Loud gradients
- Neon colors
- Harsh red warning states
- Too many equal-looking cards
- Cluttered analytics
- Entertainment/video browsing feel

## Layout Principles

- Focus session UI should be minimal.
- Timer should be the visual anchor.
- Distraction buttons should feel like soft tags or a hidden expandable menu.
- Stats should stay hidden or secondary until the user asks to review.
- Monthly analytics should feel like a calm report, not a business dashboard.
- Timeline should feel like an attention track/audio track.

## V2 Player Visual Direction

- Frosted-glass player surface.
- During playback, UI should stay almost empty.
- Distraction menu can live behind a small corner button.
- Selecting a reason can transition into a centered active distraction overlay.
- Video/background can darken or blur while a distraction episode is active.
- Stats/review panel should be hidden by default and opened like a player
  settings/effects drawer.

## Typography

- Large clean timer text.
- Light/near-white text over dark or media surfaces.
- Subtle shadow for readability.
- Avoid overly playful fonts.

## Motion

- Soft transitions.
- No flashy or game-like effects.
- Completion animation should emphasize success first.

## Privacy / Product Tone

- Local-first.
- Non-judgmental.
- Success-first completion.
- Reported focus is based only on recorded distraction time.
